## narciFarm v0.9.7

设备农场管理工具。在 v0.9.6（运营分发 + P0 自动化能力）基础上，完成 P1 工程化三项。

> ⚠️ 本项目定位是**设备农场管理工具**，不包含也不接受任何平台定向脚本、账号批量注册、流量造假或反检测/设备指纹伪装功能。请仅用于你拥有或获得授权的设备与应用。

### 产物

- **narciFarm-windows-x64.exe** — PC 端单文件程序（内置 adb 与 scrcpy-server），系统托盘常驻
- **scrcpy-server-5.0.1** — 安卓端被控服务

### 本版新增（P1 三项）

**断言增强**

- `assert_text` / `assert_el` 新增 `match` 参数：`exact` / `contains`（默认，兼容旧场景）/ `regex` / `startswith` / `endswith`
- 新增 `assert_value` 步骤：数值或变量比较，`op` 支持 `eq/ne/gt/gte/lt/lte/contains/regex`，`actual` 支持 `{{变量}}`
- 所有断言步骤支持 `soft: true`（软断言）：失败时记录到报告但**不中止**该设备后续步骤，可一次性收集多处问题
- 软断言失败仍会让报告判为失败，CI 能拦住

**录制器增强**

- **控件级录制**：勾选「录制动作」后，点击步骤在写入场景时同步解析该坐标对应的控件（优先 resource-id，其次 content-desc / 文本 / 类名），自动改写为 `tap_el` 步骤 —— 录制的场景**跨分辨率可回放**
- **▣ 框选模板**：投屏窗口内拖出矩形区域，松手即存为图像模板，可直接用于 `tap_image` / `assert_image`
- **✔ 断言 / 📷 截图**：录制过程中随时向场景插入文本断言或截图步骤，无需切回场景页

**性能指标采集与报告**

- 场景运行可选「采集性能指标」，运行期按间隔采样 CPU / 内存 / 电量 / 电池温度
- 报告新增「性能指标」表（采样数、CPU 峰值、内存峰值、电量起止、温度峰值），HTML / JSON / JUnit 均含
- 新增 `GET /api/devices/{serial}/metrics` 即时采集接口

### 接口新增

- `POST /api/devices/{serial}/resolve-at` — 把归一化坐标解析为控件选择器（控件级录制）
- `GET /api/devices/{serial}/metrics` — 即时性能指标采集

### 修复

- 修复 CSS 插入失误导致 `html, body` 被赋予 `pointer-events: none`、整页不可点击
- 修复 `/api/devices/{serial}/metrics` 路由重复注册（与既有端点冲突返回 422）
- 修复 `assert_text` 默认匹配模式变更可能导致的旧场景回归

### 测试

- 127 项自动化测试全部通过（新增断言增强、性能指标、控件命中测试、接口层覆盖）
- 浏览器回归：全部 15 个页签 + 场景编辑器新控件无未捕获异常

### 已知限制

- 中文输入仍需走剪贴板路径（adb `input text` 不支持非 ASCII）
- OCR 需系统安装 Tesseract 及中文语言包
- 控件级录制依赖录制时刻的界面状态；录制后若界面结构变化，仍需人工核对选择器
- 性能指标为轮询采样，非高频精确测量

### 合规边界（再次声明）

本工具**不做**：改机/一键新机（IMEI/SN/MEID/Android_ID 伪装）、虚拟定位、代理 IP 池、自动加好友/群发/养号/刷量、AI 内容批量生成与多平台分发。详见 `docs/竞品功能差距分析.md`。
