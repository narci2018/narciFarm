## narciFarm v0.9.10

设备农场管理工具。新增 **设备托管（Device Owner / MDM 层）**——从「测试工具」迈向「设备托管平台」。

> ⚠️ 本项目定位是**设备农场管理工具**，不包含也不接受任何平台定向脚本、账号批量注册、流量造假或反检测/设备指纹伪装功能。请仅用于你拥有或获得授权的设备与应用。

### 产物

- **narciFarm-windows-x64.exe** — PC 端单文件程序（内置 adb 与 scrcpy-server），系统托盘常驻
- **scrcpy-server-5.0.1** — 安卓端被控服务
- **参考 DPC APK**（源码，需自行构建）— 设备托管的移动端组件，见 `dpc/`

### 本版新增：设备托管（Device Owner）

**前提**：设备上需有一个 DPC（设备策略控制器）应用并设为 Device Owner。本版提供参考 DPC 源码（`dpc/`）。

**能力**

- **托管状态探测**：解析 `dumpsys device_policy`，识别是否有 Device Owner、管理员应用、Kiosk 锁定列表，以及相机/恢复出厂/截屏限制（解析不到的字段标记为「未知」而非报错）
- **Provisioning**：通过 `dpm set-device-owner` / `dpm remove-active-admin` 设置与移除 Device Owner
- **策略下发**：以 `io.narcifarm.POLICY` 广播把命令发给 DPC，支持
  - 远程锁屏、远程擦除（面板先弹确认）
  - 锁定 / 解除单应用 Kiosk
  - 停用 / 启用应用
  - 允许 / 禁止恢复出厂、禁用 / 启用相机、禁用 / 启用截屏
- **UI**：批量页新增「设备托管」面板（状态读取、Provisioning、策略命令）
- **SDK**：`policy_status` / `policy_commands` / `set_device_owner` / `remove_device_owner` / `policy_command`

**参考 DPC（`dpc/narci_dpc/`）**

最小可用的 Device Owner 应用，实现上述广播契约。构建：

```bash
cd dpc/narci_dpc && ./gradlew assembleDebug
adb install app/build/outputs/apk/debug/app-debug.apk
adb shell dpm set-device-owner io.narcifarm.dpc/.NarciDeviceAdminReceiver
```

> ⚠️ DPC 源码**未在本环境编译验证**（本地无 Android SDK）。代码按标准 Android DevicePolicyManager API 编写，请自行构建测试。不想自建时可用 Google 的 TestDPC，但 TestDPC 使用自己的广播协议，只能让 narciFarm 识别出「已托管」，不能驱动策略命令面板。

### 接口新增

| 接口 | 说明 |
|---|---|
| `GET /api/devices/{serial}/policy` | 设备托管状态 |
| `GET /api/policy/commands` | 支持的策略命令 |
| `POST /api/devices/{serial}/policy/provision` | 设为 Device Owner |
| `POST /api/devices/{serial}/policy/deprovision` | 移除 Device Owner |
| `POST /api/devices/{serial}/policy/command` | 下发策略命令 |

### 已知限制

- 设置 Device Owner 要求设备**已恢复出厂、未登录账号、未设置过 DO**；已配置账号的设备需先恢复出厂
- 策略命令需要 DPC 在线；权限不足时 DPC 侧记 SecurityException，narciFarm 逐设备报错
- 参考 DPC 未经编译验证，首次使用请自行构建并核对

### 合规边界（再次声明）

本工具**不做**：改机/一键新机（IMEI/SN/MEID/Android_ID 伪装）、虚拟定位、代理 IP 池、自动加好友/群发/养号/刷量、AI 内容批量生成与多平台分发。
设备托管能力仅用于**你拥有或获授权设备**的 Kiosk 锁定、应用限制与远程运维。详见 `docs/竞品功能差距分析.md`。
