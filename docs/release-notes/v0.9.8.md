## narciFarm v0.9.8

设备农场管理工具。在 v0.9.7（P1 工程化三项）基础上，补齐 P1 最后两项：控件树可视化拾取器、插件机制与 Python SDK。

> ⚠️ 本项目定位是**设备农场管理工具**，不包含也不接受任何平台定向脚本、账号批量注册、流量造假或反检测/设备指纹伪装功能。请仅用于你拥有或获得授权的设备与应用。

### 产物

- **narciFarm-windows-x64.exe** — PC 端单文件程序（内置 adb 与 scrcpy-server），系统托盘常驻
- **scrcpy-server-5.0.1** — 安卓端被控服务

### 本版新增（P1 收尾两项）

**控件树可视化拾取器**

- 「开发工具」页改为**树形视图**：按界面真实层级缩进展示，可展开/折叠
- 点选节点后右侧显示完整属性面板（文本、资源ID、content-desc、类名、包名、中心、边界、可点击/可滚动/启用/选中）
- 一键把选中节点插入场景：**插入 tap_el 步骤** / **插入 assert_el 步骤**（选择器自动按 resource-id → content-desc → 文本 → 类名优先级生成）
- 也可点「点击该控件」直接驱动设备

**步骤插件机制**

- 新增 `narci/plugins.py`：用 Python 模块扩展场景步骤类型，主程序无需改动
- 插件放在插件目录（默认 `<数据目录>/plugins`，或 `NARCI_PLUGINS_DIR`），暴露 `register(reg)` 即可
- 处理器签名 `async def run(step, serial, size, run_id) -> dict`
- **插件只在内置类型不匹配时生效**，因此不会覆盖原有行为
- 新增 `GET /api/plugins` 列出内置与插件类型；「开发工具 → 步骤插件」面板可视化查看
- 示例见 `examples/plugins/01_demo_steps.py`

**Python SDK（`client/`，可独立安装）**

- `pip install ./client`，仅依赖标准库
- 登录/登出、设备枚举、控件树、元素查找、性能指标、批量输入注入
- 场景创建与运行、运行状态轮询、中止、报告查询与 HTML / JUnit 导出
- CI 友好：`with Client(...) as c:` 自动登出，错误抛 `NarciError`
- 完整 API 见 `client/README.md`

### 修复

- 修复 `/api/devices/{serial}/metrics` 对不存在设备静默返回空对象（现返回 404）

### 测试

- 147 项自动化测试全部通过（新增控件树层级、插件机制与加载、Python SDK 真实 HTTP 集成）
- 浏览器回归：控件树渲染与节点取步骤、插件面板均无未捕获异常

### 已知限制

- 控件树 `uiautomator dump` 在锁屏、部分游戏/输入法界面会返回空
- 插件加载在服务启动时执行一次；新增插件需重启服务
- SDK 为纯 HTTP 客户端，不包含投屏解码（投屏仍走浏览器）

### 合规边界（再次声明）

本工具**不做**：改机/一键新机（IMEI/SN/MEID/Android_ID 伪装）、虚拟定位、代理 IP 池、自动加好友/群发/养号/刷量、AI 内容批量生成与多平台分发。详见 `docs/竞品功能差距分析.md`。
