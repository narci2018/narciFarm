## narciFarm v0.10.0

设备农场管理工具。本版新增**社媒矩阵自动化五项能力**（平台发布模板、竞品素材采集、多机协作接力、A/B 测试、评论情感分析），并修复一批实现期缺陷。

> ⚠️ 本项目定位是**设备农场管理工具**，不包含也不接受任何平台定向脚本、账号批量注册、流量造假或反检测/设备指纹伪装功能。请仅用于你拥有或获得授权的设备与应用。

### 产物

- **narciFarm-windows-x64.exe** — PC 端单文件程序（内置 adb 与 scrcpy-server），系统托盘常驻
- **scrcpy-server-5.0.1** — 安卓端被控服务
- **narciFarm-dpc.apk** — 设备托管 DPC（Device Owner）

### 本版新增

**平台发布场景模板**

- 新增 5 套预置模板：微博图文、B 站视频、微信视频号、头条文章、知乎文章
- 模板可直接「一键生成场景」，用于调度或手动运行
- 模板为只读资源，随 exe 内置（`assets/publish_templates`）；用户也可在 `data/publish_templates/` 自行扩充或覆盖

**竞品素材采集引擎**（`narci/collector.py`）

- 支持 RSS / 网页（正则）/ API 三种采集源，定时抓取同领域内容作为素材
- 按内容哈希去重，采集结果可「转为自有内容」进入内容库
- 后台循环每 5 分钟检查到期采集源，也可手动触发单源或全量采集

**多机协作接力**（`relay` / `relay_barrier` 步骤）

- `relay`：把一段子步骤委托给另一台设备执行，支持 `wait_complete` 与 `on_fail` 策略
- `relay_barrier`：同步屏障，等待同组设备全部到达后才继续
- 流水线 API 支持按设备顺序编排并一键启动

**A/B 测试**

- 多变体创建 → 一键启动（为每个变体建独立内容与分发任务）→ 互动分排序 → 结束并标记获胜变体
- 互动分 = 浏览×1 + 点赞×3 + 评论×5 + 分享×8

**评论情感分析**（`narci/sentiment.py`）

- 关键词规则评分（-1.0 ~ 1.0），支持否定词翻转，无需外部 NLP 依赖
- 互动消息自动打标签，负面评论（≤ -0.5）触发告警
- 支持批量分析与按情感筛选

### 本版修复

**采集引擎（`narci/collector.py`）**

- 采集失败时不再写入 `last_collect`，否则重试间隔会被重置，故障源要等满一个周期才重试
- `total_collected` 改为从数据库取最新值，避免使用过期的内存快照
- RSS / 网页采集原先在 `async with httpx.AsyncClient` 块外读 `r.text`，客户端关闭后可能取不到响应体，改为块内取出
- API 采集增加返回类型校验，非预期结构不再抛异常

**场景引擎（`narci/scenario.py`）**

- `_finalize_run` 去掉重复的运行记录判空

**情感分析（`narci/sentiment.py`）**

- 否定词减弱权重误用了外层循环最后一个关键词的权重，改为按当前关键词查表取值

**前端（`static/js/app.js`）**

- 设备列表复选框缺少 `device-cb` 类名与 `value`，导致「多机协作流水线」永远取不到设备（始终为空）

**打包（`narciFarm.spec` / `narci/config.py`）**

- 发布模板原先只落在 `data/`（被 gitignore，且 spec 只打包 `static`/`assets`），发布版 exe 里没有任何模板 —— 本版起内置模板随包分发，并在无用户目录时自动回退

### 测试

- 300 项自动化测试全部通过（含新增回归测试：内置模板必须随包存在、模板路由装饰器不得错位）

### 已知限制

- 采集器的网页抓取基于正则，对复杂页面结构需手工配置匹配模式
- A/B 测试的互动数据需从各平台回写后才有分析意义，本版提供手动录入接口
- 情感分析为关键词规则，语义反讽/隐晦表达可能误判
- 运行时行为（真机发布、风控触发、托管策略）仍需在真机验证

### 合规边界（再次声明）

本工具**不做**：改机/一键新机（IMEI/SN/MEID/Android_ID 伪装）、虚拟定位、代理 IP 池、自动加好友/群发/养号/刷量、AI 内容批量生成与多平台分发。
多机协作与分发调度仅用于**你拥有或获授权设备**的运维与内容管理。详见 `docs/竞品功能差距分析.md`。
