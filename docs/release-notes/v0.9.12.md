## narciFarm v0.9.12

设备农场管理工具。本版把**参考 DPC APK 纳入 CI 构建并随 Release 分发**——设备托管能力现在开箱可用。

> ⚠️ 本项目定位是**设备农场管理工具**，不包含也不接受任何平台定向脚本、账号批量注册、流量造假或反检测/设备指纹伪装功能。请仅用于你拥有或获得授权的设备与应用。

### 产物

- **narciFarm-windows-x64.exe** — PC 端单文件程序（内置 adb 与 scrcpy-server），系统托盘常驻
- **scrcpy-server-5.0.1** — 安卓端被控服务
- **narciFarm-dpc.apk** — 设备托管 DPC（Device Owner），本版起随 Release 自动构建分发

### 本版变更

**DPC 纳入 CI 构建**

- 新增 `.github/workflows/dpc.yml`：安装 Android SDK（platform-34）+ Gradle 8.7 构建 `assembleDebug`，产出 Artifact
- release 工作流新增 `build-dpc-apk` job，打 tag 时自动构建并附加到 GitHub Release
- 补齐 `dpc/narci_dpc/` 的 Gradle 工程文件（settings / build / gradle.properties / app/build.gradle）

**修复 DPC 编译错误（由 CI 发现）**

- `DevicePolicyManager.uninstallCaCert(ComponentName, byte[])` 的第二个参数是**证书的 DER 字节**，不是别名。
  `clear_ca_certs` 改为传设备上的证书文件路径，内部 PEM → DER 后再卸载
- manifest 去掉 AGP 8 已废弃的 `package` 属性，改用 `namespace`

**状态说明更新**

此前版本标注「参考 DPC 未编译验证」。本版起 DPC 由 CI 实际构建并**通过编译验证**（AGP 8.5.2 + Kotlin 1.9.24，compileSdk 34）。
运行时行为（Device Owner 设置是否成功、策略命令是否生效）仍需在真机上验证——本机没有连接设备。

### 测试

- 192 项自动化测试全部通过（无回归）
- DPC 编译：CI 构建成功，产出 `narciFarm-dpc.apk`（约 1.9 MB）

### 已知限制

- 设置 Device Owner 要求设备已恢复出厂、未登录账号、未设置过 DO
- 运行时行为未在真机验证（本机无设备接入）

### 合规边界（再次声明）

本工具**不做**：改机/一键新机（IMEI/SN/MEID/Android_ID 伪装）、虚拟定位、代理 IP 池、自动加好友/群发/养号/刷量、AI 内容批量生成与多平台分发。
设备托管与网络配置仅用于**你拥有或获授权设备**的 Kiosk 锁定、应用限制与运维。详见 `docs/竞品功能差距分析.md`。
