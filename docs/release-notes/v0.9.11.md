## narciFarm v0.9.11

设备农场管理工具。在 v0.9.10 设备托管基础上补齐 **网络配置下发**——P3 全部完成。

> ⚠️ 本项目定位是**设备农场管理工具**，不包含也不接受任何平台定向脚本、账号批量注册、流量造假或反检测/设备指纹伪装功能。请仅用于你拥有或获得授权的设备与应用。

### 产物

- **narciFarm-windows-x64.exe** — PC 端单文件程序（内置 adb 与 scrcpy-server），系统托盘常驻
- **scrcpy-server-5.0.1** — 安卓端被控服务
- **参考 DPC 源码**（需自行构建）— 见 `dpc/`

### 本版新增：网络配置下发（Wi-Fi / VPN / 证书）

**Wi-Fi**：Device Owner 可免用户确认地配置 Wi-Fi（SSID、密码、是否隐藏），面板下发即生效。

**始终开启 VPN**：`setAlwaysOnVpnPackage` 设置或关闭「始终开启」VPN。

**CA 证书安装**：上传 `.crt/.pem/.cer/.der` 证书 → 推到设备 → DPC 装入系统信任库（PEM 自动转 DER）。
新增接口 `POST /api/devices/{serial}/ca-cert`，SDK 提供 `install_ca_cert`。

### 参考 DPC 更新

`PolicyReceiver` 新增 `set_wifi` / `set_always_on_vpn` / `install_ca_cert` / `clear_ca_certs` 四条命令，
manifest 补充 Wi-Fi 相关权限，广播参数支持 `--ei`（整数）。

### 接口

| 接口 | 说明 |
|---|---|
| `POST /api/devices/{serial}/ca-cert` | 上传并安装 CA 证书 |

策略命令扩展为：`set_wifi`、`set_always_on_vpn`、`install_ca_cert`、`clear_ca_certs`。

### 测试

- 192 项自动化测试全部通过（新增网络策略命令、证书推送与上传接口）
- 浏览器回归：设备托管面板的网络配置区渲染正常，无未捕获异常

### 已知限制

- Wi-Fi/VPN/证书安装均需 DPC 是 Device Owner；权限不足时 DPC 侧记 SecurityException
- CA 证书安装为系统级信任，影响该设备所有应用——仅在你拥有或获授权的设备上使用
- 参考 DPC 仍未编译验证（本地无 Android SDK），请自行构建

### 合规边界（再次声明）

本工具**不做**：改机/一键新机（IMEI/SN/MEID/Android_ID 伪装）、虚拟定位、代理 IP 池、自动加好友/群发/养号/刷量、AI 内容批量生成与多平台分发。
设备托管与网络配置仅用于**你拥有或获授权设备**的 Kiosk 锁定、应用限制与运维。详见 `docs/竞品功能差距分析.md`。
