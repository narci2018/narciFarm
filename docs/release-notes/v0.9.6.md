## narciFarm v0.9.6

设备农场管理工具。一台 PC 管理 N 台安卓设备：多路投屏、群控广播、场景编排、定时调度、批量操作、测试报告。

> ⚠️ 本项目定位是**设备农场管理工具**，不包含也不接受任何平台定向脚本、账号批量注册、流量造假或反检测/设备指纹伪装功能。请仅用于你拥有或获得授权的设备与应用。

### 产物

- **narciFarm-windows-x64.exe** — PC 端单文件程序（内置 adb 与 scrcpy-server）。无控制台窗口，启动后系统托盘常驻（打开管理台 / 关闭服务），数据与日志在 exe 同级目录。
- **scrcpy-server-5.0.1** — 安卓端被控服务，与 exe 内置的官方预编译版同版本，可互换。

### 本版新增

**运营与分发**

- 账号库（平台 / 账号名 / 用户名 / API Token / 网关地址），账号与设备绑定
- 内容库（文本 / 图片 / 视频，支持媒体上传）
- 分发任务调度（内容 + 账号 + 计划时间，到点自动执行；支持 Webhook 发布器）
- 设备标签（任意键值，便于分组与筛选）
- 反向端口转发（设备端口 → PC 端口，便于抓包与本地联调）

**自动化能力（P0 五项）**

- **控件树与多维元素定位**：新增 `tap_el` / `wait_el` / `assert_el` / `swipe_el` 步骤，支持 `text`、`id`(resource-id)、`desc`(content-desc)、`class`、`package`、`xpath` 六种维度，可模糊匹配、可取第 N 个匹配。「开发工具」页新增控件树面板，可查找、查看属性、直接点击。
- **OCR 坐标级点击**：`ocr_tap` 现在**真的点击**——按识别框中心注入触控，而非仅校验文字是否存在。新增 `ocr_find` 步骤与 `vision.ocr_find()`（返回文本 + 边界框 + 置信度），支持区域 OCR 与坐标换算。
- **步骤级失败重试**：所有步骤支持 `retry`（次数）、`retry_interval_ms`（退避间隔）、`on_fail`（`abort` 终止 / `continue` 跳过继续），用于应对弹窗、动画、网络抖动等瞬时失败。
- **测试报告导出**：场景运行结束自动生成报告并落盘 `reports/`（重启不丢），支持 JSON / 自包含 HTML / JUnit XML 三种格式，可接入 Jenkins、GitLab CI、GitHub Actions。新增「报告」页签。
- **图像匹配增强**：新增 `find_image` 步骤与 `match_all()`，支持多结果、多尺度金字塔、区域限定、NMS 去重；新增 `/api/devices/{serial}/match-image` 调优接口。

**工程质量**

- 修复运营页签无法打开：ops 代码块被误插入 `showMain()` 内部导致函数不在全局作用域
- 修复 `/api/device-tags` 缺失、`dt-account` 下拉被设备序列号覆盖
- 修复登录页未登录即轮询导致的 401 噪声与未捕获异常
- 修复 `/api/version` 被鉴权中间件拦截（版本号显示为 `?`）
- 修复测试隔离缺陷：`NARCI_DATA_DIR` 移入 `conftest.py`，避免测试连到真实数据库

### 测试

- 82 项自动化测试全部通过（新增控件定位、OCR 坐标、重试、报告、图像匹配、接口层覆盖）
- 浏览器回归：全部 15 个页签无未捕获异常

### 已知限制

- 中文输入仍需走剪贴板路径（adb `input text` 不支持非 ASCII）
- OCR 需系统安装 Tesseract 及中文语言包
- 控件树 `uiautomator dump` 在锁屏、部分游戏/输入法界面会返回空
- 当前版本未做真机端到端验证（发布前请在插有手机的机器上跑一遍控件树与 OCR 面板）

### 合规边界（再次声明）

本工具**不做**：改机/一键新机（IMEI/SN/MEID/Android_ID 伪装）、虚拟定位、代理 IP 池、自动加好友/群发/养号/刷量、AI 内容批量生成与多平台分发。这些功能在竞品中高频出现，但与「真实设备管理」定位冲突且法律风险最高，已明确列为 non-goal（详见 `docs/竞品功能差距分析.md`）。
