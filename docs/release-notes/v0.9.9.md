## narciFarm v0.9.9

设备农场管理工具。补齐 P1 最后两项：设备快捷操作、弱网模拟。至此 P0 + P1 全部完成。

> ⚠️ 本项目定位是**设备农场管理工具**，不包含也不接受任何平台定向脚本、账号批量注册、流量造假或反检测/设备指纹伪装功能。请仅用于你拥有或获得授权的设备与应用。

### 产物

- **narciFarm-windows-x64.exe** — PC 端单文件程序（内置 adb 与 scrcpy-server），系统托盘常驻
- **scrcpy-server-5.0.1** — 安卓端被控服务

### 本版新增（P1 收尾两项）

**设备快捷操作（P1-6）**

- 批量页新增「设备快捷操作」面板：找机（亮屏）、锁屏、解锁、开/关飞行模式、重启、关机、保持唤醒，以及按包名「结束应用」「清除数据」
- 危险动作（关机、清除数据、重启）先弹确认
- 新增场景步骤：`reboot`（可选等待上线）、`locate`、`airplane`、`lock`、`unlock`
- 新增接口 `GET /api/batch/actions` 与 `POST /api/batch/action`（逐设备返回成功/失败）

**弱网模拟（P1-7）**

- 新增本地节流代理 `narci/netlimit.py`：把设备全局 HTTP 代理指向它即可模拟窄带/高延迟/丢包
- **真机无需 root**：普通 HTTP 请求解析后限速转发；HTTPS 走 CONNECT 隧道限速（不做中间人解密）
- 支持带宽（kbps）、固定延迟（ms）、丢包率（%）三个维度
- 批量页新增「弱网模拟」面板，可随时开启/关闭；关闭即清除设备代理
- 新增接口 `GET /api/netlimit/status`、`POST /api/netlimit/start`、`POST /api/netlimit/stop`
- Python SDK 同步提供 `netlimit_status/start/stop`

### 接口新增

| 接口 | 说明 |
|---|---|
| `GET /api/batch/actions` | 可用的批量快捷操作清单 |
| `POST /api/batch/action` | 对多台设备执行快捷操作 |
| `GET /api/netlimit/status` | 当前弱网模拟状态 |
| `POST /api/netlimit/start` / `stop` | 开启 / 关闭弱网模拟 |

### 测试

- 168 项自动化测试全部通过（新增快捷操作、批量接口、节流代理与速率限制的实测）
- 浏览器回归：批量页快捷操作与弱网面板渲染正常，无未捕获异常

### 已知限制

- 弱网模拟依赖设备能访问到 PC 的代理端口（同一局域网或已 `adb reverse`）；HTTPS 只做隧道限速，不解密
- 飞行模式指令在部分厂商机型上需要额外权限，失败时逐设备报错而不影响其他设备
- 重启/关机会断开 adb 连接，批量结果里可能缺少该设备的回执

### 合规边界（再次声明）

本工具**不做**：改机/一键新机（IMEI/SN/MEID/Android_ID 伪装）、虚拟定位、代理 IP 池、自动加好友/群发/养号/刷量、AI 内容批量生成与多平台分发。详见 `docs/竞品功能差距分析.md`。
